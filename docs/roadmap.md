## 0. 工作流程

1. 读本文，按能力规范确定本次涉及的能力 ID。
2. 开工前创建 `iteration/<YYYY-MM>/<YYYY-MM-DD>-<category>-<name>.md`，写清目标、范围、设计、验证、风险与回退。
3. 执行、测试、顾问 review；阻塞意见须核实、修复、重跑验证并按需复审。变异验证按风险采用。
4. 更新长期产品/架构结论，回写本文中的状态、证据、偏差与后续任务。
5. 当前任务完成后再选择下一项；发现范围或依赖失效时，先暂停受影响工作并讨论更新计划。

小型无行为维护不单建迭代。分类使用 `feat` / `perf` / `bugfix` / `refactor` / `test`。能力完成需符合规范的单项开发验收，不能以 SDK 或组件存在替代。

## 2. 当前主线：G1 Pi 基础能力 GUI 化

### 2.1 范围与退出标准

能力定义与验收唯一来源为 [Pi GUI 能力规范](pi-gui-capabilities.md)。仓库已统一使用 Pi **1.4.0**；升级及回归证据见 G1.1 迭代记录。全部适用能力须有 GUI 等价入口，例外须经用户确认。

默认沿用 Pi 用户空间，允许手工指定其他目录；自动化使用隔离空间。继续采用浏览器 + Node / SDK，不先做文件回滚、IDE 工作台或桌面打包。基础开发验收与真实使用问题共同驱动自迭代，手工平台验证不阻塞开发迭代完成。

## 3. M4 工作区增强（延后）

原 M4 的 Pi 生态兼容、项目选择、会话管理、基础输入与快捷操作已迁入 G1，不再在此重复维护。剩余范围：

- 文件树、Monaco 只读查看与大型文件性能；忽略策略与未来快照共享判定。
- 文件树 / 查看 / Diff / 聊天的可拖拽布局。
- 超出 Pi 原生输入能力的附件扩展，以及真实使用驱动的进一步体验优化。

启动前按实际痛点重定顺序与退出标准。持续遵循流式更新不阻塞输入、长列表性能、键盘路径与 i18n 约束。

## 4. M5 末语工坊接入（延后）

目标：验证公共库支撑第二个应用；启动前依据末语工坊实际文档与代码细化边界（D-17）。公共层继续保持可复用包边界，不为尚不存在的消费路径新增抽象。

| 工作包 | 范围 |
| --- | --- |
| Editor Bridge | 经编辑器服务接口 / store actions 访问业务状态，不直接读写磁盘 |
| 编辑器工具 | 只读上下文、增删节点/改属性/绑定资源、选择确认、预览校验 |
| Tool UI | 按 toolName / rendererId 注册，缺少专用组件时通用回退仍可读 |
| 事务撤销 | 写入经既有校验、通知和 Undo/Redo，支持未保存状态 |

约束：不提供通用 Shell、任意路径读写；不加载用户通用扩展目录的任意代码；主线程不被长任务阻塞，异步操作考虑 UI 生命周期；威胁模型为防误操作和 Prompt Injection 围栏，不承诺 OS 沙箱。

退出标准在迭代设计时细化，至少包含未保存状态下“读上下文 → 改场景 → 撤销”、历史通用回退及受控工具面。

## 7. M3 文件快照与变更审查（延后，保留设计）

本节保留原目标与边界，当前不启动实现。D-16 内容寻址与 D-07 恢复独立语义继续有效，原 D-18 优先排期已由 §1 的新决定替代。

### 7.1 目标与范围

| 工作包 | 保留的设计范围 |
| --- | --- |
| 内容寻址后端 | blob 按内容 hash；manifest 记录路径、hash 与元数据；应用数据目录存储，不写工作目录；run 起止 / tool 前后增量扫描 |
| 存储与忽略 | 尊重 `.gitignore` 等及内置排除；孤儿 blob 回收，manifest 带版本，对象库可独立重建 |
| ChangeSet 与归因 | 两份 manifest 之差与 run/tool/时间/操作者元数据；区分 Agent 与用户改动；不依赖 Git、不碰 index，Git 只可能作为加速层 |
| Provider | `@huan/history` 的 capture/diff/restore，表达不支持、部分成功、冲突、确认、中断；选择性恢复由 capability 声明 |
| 审查与恢复 | Monaco 文本 Diff、文件树、二进制摘要与冲突；先文件级接受/撤销，hunk 后续；恢复前检查外部改动，不静默覆盖 |

### 7.2 开工前需细化

- 应用数据路径、多应用/多工作区隔离、对象库与 manifest 布局。
- 未跟踪/忽略文件、重命名、符号链接、权限位、大文件阈值和归因可信边界。
- Agent 运行中恢复的禁用/先中止规则；大仓库扫描性能及增量策略。
- Monaco 延迟加载、worker 与未来桌面打包配置。

文件树与快照共享忽略判定；项目文件能力统一称“快照 / FileSnapshot”，区分末语工坊 marker checkpoint。Shell、网络、数据库等外部副作用不承诺恢复。会话树切换与项目恢复必须是显式独立操作。
