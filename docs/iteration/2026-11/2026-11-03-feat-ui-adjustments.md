# UI 与交互调整

日期：2026-11-03。分类：feat。基线：`ea1c40a`。本轮统一记录用户后续提出的UI与相关产品逻辑调整，按批次追加需求、设计和执行证据，沿用本文，不为每次反馈新建文档。计划状态唯一维护于[主路线图](../../roadmap.md)。

## 1. 范围与约束

安排在G1.5之前；按下列批次调整界面。保留Base UI、Geist、明暗主题、紧凑尺度与4px圆角；不变更状态所有权、会话操作、协议或服务端数据。未归属会话管理尚无具体需求，本批不实施。代码高亮留后续讨论，本批只解决换行。

## 3. 验证与执行

主agent整体调研和设计；local/deepseek-v4.1-flash:max实施，主agent独立review、修正与亲自验证。隔离浏览器8899/8898，单worker单套，临时用户空间和合成模型；不触碰个人凭据及8799/8788，不push。

浏览器检查：短内容到溢出时视口/消息内容横坐标与宽度保持，滚轮/键盘/拖动轨道和回底仍有效；输入聚焦无ring且border变化；工具长参数与输出换行且复制一致；Tooltip复制/引用等入口不被箭头遮住，明暗主题与侧边翻转定位正确。源码/CSS/DOM几何和截图视觉分别记录，未实际看图不能声称视觉通过。

每批按改动执行必要的针对性检查，完整测试、构建和浏览器回归统一在本轮结束时进行；按用户最新要求，期间保持未提交状态。Markdown仍须每次全文风格零命中，检查链接与diff。回退只涉及本轮改动，不涉及用户数据。

### 5.6 两层模型范围：产品规则

用户提出全局设置与工作区覆盖两层模型范围，会话只从最终范围挑选模型。此规则取代旧“会话范围＋可选保存用户默认”的交互，以及此前将范围仅作为常用模型列表的建议。实现与验证见§5.7。

| 层级 | 数据与行为 | 界面入口 |
| --- | --- | --- |
| 全局 | 对应Pi用户settings.json的enabledModels，使用Pi模型模式解析；未设置或空数组沿用Pi语义，表示全部可用模型 | 全局设置中的模型范围；管理时展示完整目录 |
| 工作区 | 默认继承全局；启用自定义后完整替换全局范围，允许选取全局范围外但在完整目录中可用的模型；保存到huan工作区定义，不写某个成员项目的settings.json | 工作区设置中的模型范围；提供“跟随全局/自定义” |
| 会话 | 移除独立会话范围编辑，仅选择最终范围内的模型；新会话预选与主动切换从最终范围选择；已有会话继续使用其当前模型 | 输入区模型选择器仅列最终可用候选；运行操作移除模型范围与目录管理 |

工作区继承用字段缺失表达，自定义要求至少一个模型模式；不让空数组同时承担继承与无模型含义。模式无匹配或匹配模型均缺凭据时显示无可用候选和配置/认证入口，不扩大为全部模型。未归属会话使用全局范围。其他成员项目的enabledModels不再构成第三层覆盖；全局兼容Pi用户配置，huan工作区覆盖为新增产品能力。patterns通配与Thinking后缀保留Pi解析规则，普通编辑用模型多选，高级编辑按需展开。

用户确认范围变更后，已有会话按旧模型数据继续使用和发送。范围只用于新建和用户主动选择模型。实现范围排除自动切换、发送拦截、修正提示、数据迁移，以及为旧值增加的恢复流程、额外并发校验和补偿机制。

### 5.10 打开会话后列表排序稳定

用户发现选中未归属会话后条目移到底部。已定位数据链：SessionCatalog.listThreads通过Pi SessionInfo提供createdAt/updatedAt；SessionEvents.metadataOf的live元数据省略这两个字段；前端applySnapshot按完整快照整体替换，已有时间随之丢失，侧栏使用空时间排序键，条目移到末尾。该路径也适用于工作区会话。

上游Pi 1.4.0的SessionInfo.created来自会话header.timestamp；modified取全文件user/assistant消息的最大活动时间，优先message.timestamp，缺失时使用entry.timestamp，无有效活动消息时回退header时间，最后才是文件mtime。因此通常排序时间不是文件修改时间，打开、改名、切换分支本身不应视为对话活动。SessionManager公开getHeader/getEntries/getEntryCount等接口，可从内存记录计算相同语义，无需为每次快照stat文件；未发现直接公开的最近活动时间getter。

服务端当前在列表和详情中额外补时间，快照构造路径却省略时间，导致同一HarnessThreadMetadata在不同入口的完整性不一致。用户随后要求继续调查与修复，确定在服务端统一元数据投影，前端完整快照替换规则保持原样。
