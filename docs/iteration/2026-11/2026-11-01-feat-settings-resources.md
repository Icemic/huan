# G1.4a 设置与资源清单

日期：2026-11-01。上层范围见[阶段设计](2026-11-01-feat-configuration-resources-auth-mcp.md)，状态见 [roadmap](../../roadmap.md)。

## 目标与范围

交付 MOD-03、RES-01：提供所选会话或空白页起始 cwd 的用户/项目 settings.json 编辑与生效来源，展示实际加载的指令、system prompt、扩展、skill、模板、主题、packages 与诊断。每阶段完成后提交再继续。

## 设计

1. 新增 JSON-safe settings/resources 协议与宿主接口。查询目标 threadId/workspacePath 二选一，复用已授权项目和选定 agentDir；不允许调用方指定任意配置文件路径。项目未信任时不读取其受保护设置内容，不允许写项目配置；用户设置仍可编辑。
2. 返回用户/项目原文、文件路径、SHA-256 revision、解析/校验错误、SDK 合并生效值和来源。原文可损坏，GUI 保留供修复。原文编辑采用乐观 revision 拒绝其他窗口旧保存。只替换指定文件，保留 JSON 未知字段；常用表单改动原对象对应键，不重建整个配置。密码不写日志；配置页面仅显式请求时读取原文，不附到会话快照。
3. 使用 SDK 公共 getPackageDir() 定位随包分发的 schemas/settings.schema.json；使用成熟 JSON Schema 2020 校验器（优先 AJV 8 满足发布龄版本），不导入私有 SettingsSchema。校验已知字段并允许未知字段透传；源 schema 若禁止未知字段，仅调整顶层 additionalProperties 以保留扩展配置。读写有合理大小上限。拒绝原型污染键，支持不存在文件 revision。原子临时写入+rename 与宿主 settingsWrites 串行，失败不改 live 缓存；既有自动压缩/模型范围写入共享同一写队列。
4. 保存与应用分开。保存后返回当前磁盘合并预览、明确提示资源/常用运行设置须重载后应用；sessionDir、启动环境和代理等需重启宿主。当前会话不被静默替换模型/Thinking。G1.4b 接入 reload；a 阶段可发现“已保存，待重载”的说明。不虚报写盘成功。保持现有自动压缩快捷开关自身语义。
5. 资源清单来自现有 ResourceLoader getters 和 SettingsManager，不额外执行扩展、不联网重扫；空白页沿用现有受信装配缓存。指令/system prompt 文本按显式页面查询显示；packages 显示声明与实际资源 sourceInfo，未被加载的受保护资源说明信任边界。热会话展示正在使用的 loader，不能把磁盘新内容说成已加载。
6. 新增 Base UI 设置/资源 Dialog 与可发现按钮，/settings 打开同一面板；用户/项目作用域切换、常用项（默认模型/Thinking、队列、重试、压缩、默认工具、skill 命令、传输/图像）+ JSON 编辑、重置改动、保存冲突与错误。区分浏览器主题和 Pi 终端参数，不改变已有模型选择器的会话临时语义。初始/切换响应有代次防串页，弹层仅打开时订阅/查询。

## 验证

- 临时空间覆盖用户/可信项目优先级、未知嵌套字段、损坏原文修复、非法类型拒绝、不存在文件、冲突保存、原子失败、未信任拒绝、与旧自动压缩/范围保存串行。
- 资源清单含真实 loader 的指令/模板/skill/扩展和来源，未信任项目不执行；热会话清单保持加载态。
- HTTP 的目标互斥/大小上限/错误码与客户端响应校验；浏览器 /settings 与按钮、常用项/JSON、作用域/保存提示、冲突与资源来源。
- 主 agent review 与亲验 pnpm check/build、相关浏览器及必要完整回归，确认后本地提交。本轮不申请用户真实凭据。

## 风险与回退

JSON 编辑可能包含无关字段删除，UI 明确完整文件语义、切换未保存内容保留/提示。仅单宿主支持写入事务，revision 防止多窗口旧值；外部进程跨检查/rename 窗口不承诺强事务。配置生效与保存状态分开。回退仅撤销该阶段代码，已写配置仍为 Pi 标准文件格式。
