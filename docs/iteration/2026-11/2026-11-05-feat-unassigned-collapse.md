# 未归属会话分组折叠

日期：2026-11-05

## 1. 目标与范围

未归属会话采用与工作区一致的标题行与会话缩进，支持展开、收起。分组继续表示未关联工作区的会话集合，服务端数据模型与扫描规则保持原样。

## 2. 设计

- 标题行使用既有工作区行的高度、字号、箭头和数量样式，整行按钮切换展开状态；支持 Enter、Space，提供 aria-expanded 与 aria-controls。
- 默认展开，沿用现有可见性。折叠后保留标题和数量，隐藏会话行；筛选或目录刷新保留用户选择。
- 独立布尔状态归 workspace feature store，以独立 sessionStorage 键按服务地址与会话存储作用域恢复；与工作区 ID 集合分开保存。
- 分组仅有展开动作，工作区选择、创建、管理和会话归属逻辑沿用现有实现。
- 业务组件组合既有按钮、图标和会话行，无需增加或修改通用基础组件。

## 3. 验证与回退

定向状态测试覆盖保存、恢复、作用域隔离与销毁；浏览器沿用未归属接入用例，覆盖鼠标/键盘折叠、刷新恢复、继续打开及明确加入工作区。运行应用与 e2e 类型、定向代码检查和文案提取；主 agent 独立检查并读取截图。

回退时撤回本次 UI 与状态变更。会话文件及服务端元数据均沿用现有格式。
