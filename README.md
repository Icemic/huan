# 幻 · huan

按开发者个人喜好开发的 Pi GUI Harness，支持多项目工作区、多端实时同步，沿用 Pi 生态，并计划提供文件快照与回滚（WIP）。

[开始使用](#开始使用) · [功能特色](#功能特色) · [开发指南](docs/dev-guide.md) · [开发计划](docs/roadmap.md)

> 开发中。目前从源码运行，文件快照与回滚尚待实现。

## 功能特色

| 功能 | 用起来是什么样 |
| --- | --- |
| **多项目工作区** | 把相关项目放在一起，用 `@项目别名/路径` 跨项目读写和搜索。项目可以加入多个工作区，会话按工作区整理。 |
| **多端实时同步** | 多个浏览器连接同一后端，同步查看对话、任务进度和待答请求。关掉页面，任务继续；各窗口保留自己的草稿。 |
| **会话树与分支** | 回看对话树、标记节点、跳转历史，或从某条消息分叉出新会话，换个思路继续聊。 |
| **文件快照与回滚 · WIP** | 计划记录文件改动、区分 Agent 与手动修改，支持差异审查和按文件恢复，恢复前检查外部改动。 |
| **沿用 Pi 生态** | 使用已有的 Pi 配置、模型认证、Skills、提示词模板和扩展，在界面中管理 MCP；无需另外安装 Pi CLI。 |
| **实时用量与速度** | 任务进行中查看主、子 Agent 的输出用量、平均速度、耗时与首响应时间，结束后仍可查看。 |
| **按工作区选模型** | 为不同工作区设置模型候选，在会话中切换模型和思考强度。全局设置也可以直接沿用。 |
| **代码高亮与主题** | Markdown、文件内容、编辑差异和命令输出各有合适的展示。提供浅色、深色、One Dark 与 Solarized Light 四种主题。 |
| **个人习惯优先** | 中文优先、紧凑布局，围绕开发者自己的日常使用持续调整。功能和交互会随着实际需求变化。 |

会话树跳转已经可用，改变的是对话上下文；文件恢复属于 WIP。自定义终端 TUI 扩展需要适配 GUI。

## 开始使用

需要 **Node.js ≥ 22.19.0** 和 **pnpm 10.x**。开发验证以 Windows 为主。

### 1. 获取源码并安装依赖

```bash
git clone https://github.com/Icemic/huan.git
cd huan
pnpm install
```

### 2. 启动

在仓库目录打开两个终端，分别运行：

```bash
pnpm --filter @huan/harness dev:server
```

```bash
pnpm dev
```

### 3. 开始聊天

打开 **<http://localhost:8799/>**，在「设置 → 模型与服务商」配置认证，添加工作区和项目，选择模型后开始聊天。

已有 Pi 配置时，默认沿用 `~/.pi/agent` 下的配置和认证。更多运行配置见[开发指南](docs/dev-guide.md#72-服务配置)。
